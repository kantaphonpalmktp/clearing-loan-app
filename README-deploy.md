# ระบบเคลียร์เงินยืมกิจกรรม — คู่มือ

เว็บแอปไฟล์เดียว **ไม่ต้องมี backend / API key / ค่าใช้จ่าย** — อ่านรูปในเครื่องด้วย Tesseract.js แล้วแมปชื่อกับ “รายชื่อทีม” อัตโนมัติ

## ไฟล์
- `ระบบเคลียร์เงินยืมกิจกรรม.html` = แอป (เปิดในเครื่องได้เลย ดับเบิลคลิก)
- `index.html` = สำเนาเดียวกัน (ชื่อมาตรฐานสำหรับ deploy)

## ใช้งาน (4 ขั้น)
1. **กิจกรรม + วันเวลา** — ชื่อกิจกรรม / ผู้ถือเงิน / วันเวลาไป-กลับ
2. **อัปโหลดรูป → ตรวจตาราง** — กด “📸 อ่านรูปลงตาราง” ระบบดึงชื่อ+ยอด • เทียบ **ยอดรวมล่างสุด** กับรูป แล้วแก้ช่องที่เพี้ยน
3. **ค่าใช้จ่าย** — เลือกผู้สำรองจ่ายค่าที่พัก/เครื่องบิน/รถ + ยอดจ่ายจริง
4. **สรุป** — ดู ✔ ยอดตรง แล้วคัดลอกข้อความ (LINE) / พิมพ์ PDF / CSV / บันทึกไฟล์

## Save / ทำต่อ
- **💾 บันทึก** → ได้ไฟล์ `.json` (เก็บทุกอย่างรวมรูป + ขั้นที่ทำค้าง) → **📂 เปิดไฟล์** เพื่อทำต่อ
- ระบบยังจำอัตโนมัติในเครื่อง (เปิดมาข้อมูลล่าสุดอยู่)

## ความแม่นยำในการอ่านรูป
- **ตัวเลข** Tesseract อ่านได้ดี (ตารางดิจิทัลชัด)
- **ชื่อไทย** อาจเพี้ยน แต่ระบบ **จับคู่กับรายชื่อทีม 12 คนอัตโนมัติ** (แก้ ณ/น/ศ ฯลฯ ให้) — ชื่อนอกลิสต์เก็บตามที่อ่านได้
- ทุกครั้ง **ตรวจยอดรวมล่างสุดของตารางให้ตรงกับรูป** = ยืนยันจำนวนคนครบ + ยอดตรง

## Deploy ขึ้น Cloud (ฟรี, เป็น static site)
ไม่มี backend จึง deploy ง่ายมาก:
- **Vercel**: `npm i -g vercel` → `vercel` (ไม่ต้องตั้งค่าอะไรเพิ่ม เสิร์ฟ index.html)
- **Cloudflare Pages / GitHub Pages / Netlify**: อัปโฟลเดอร์นี้ได้เลย
> Tesseract.js โหลดจาก CDN ตอนกดอ่านครั้งแรก (ต้องต่อเน็ตครั้งแรก) — ถ้าต้องการออฟไลน์ 100% แจ้งได้ จะฝังไลบรารีลงในไฟล์ให้

## แก้ไขรายชื่อทีม
เปิดไฟล์ .html แก้ตัวแปร `DEFAULT_ROSTER` (บนสุดของ `<script>`) ให้เป็นรายชื่อจริงของทีม
